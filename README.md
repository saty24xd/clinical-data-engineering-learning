# Clinical Data Engineering - Practice Repo

A practice repository for learning Git and GitHub workflows in clinical data engineering.

## What is this?

This repo documents my hands-on practice with version control for clinical data pipelines:
- Basic Git workflow (init, add, commit, push, pull)
- Branching and Pull Requests
- Protecting sensitive clinical data with `.gitignore`

## How to clone this repository

```bash
git clone https://github.com/saty24xd/clinical-data-engineering-learning.git
cd clinical-data-engineering-learning

```
## What I learned

- Never commit PHI/PII or raw clinical datasets to Git
- Use clear commit messages in English
- Work on feature branches and merge via Pull Request
- Keep main stable and up to date with git pull
